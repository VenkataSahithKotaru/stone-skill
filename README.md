# Stone & Skill

Build a modern, professional, responsive portfolio website for my father, who is a skilled tile installation worker.

The main purpose of the website is to showcase his tile work, completed projects, craftsmanship, and experience to potential customers, contractors, friends, and professional contacts.

The website should feel like a premium local craftsmanship portfolio rather than a generic corporate construction website.

Overall Design

Create a clean, elegant, visually impressive design with:

Warm neutral colors inspired by stone, marble, ceramic, and natural materials

White / off-white backgrounds

Charcoal or dark gray text

Subtle earthy accent colors

Large, high-quality project photography

Plenty of whitespace

Modern typography

Smooth animations and transitions

Subtle hover effects

Mobile-first responsive design

Professional but approachable personality

The website should communicate:

Quality craftsmanship • Attention to detail • Experience • Reliability • Pride in work

Avoid making the website look overly flashy, corporate, or like a large construction company. It should represent an experienced individual craftsman.

Website Structure

Create the following sections/pages.

1. Home / Hero Section

Create a strong hero section immediately showing what he does.

Headline:

"Quality Tile Work, Built to Last."

Subheadline:

"Professional tile installation and finishing with attention to detail, precision, and craftsmanship."

Include two prominent buttons:

"View My Work"

"Get in Touch"

Use a large background image or project image showing beautiful tile installation.

Add a small trust statement underneath:

"Experienced Tile Work • Residential & Commercial • Quality Craftsmanship"

2. About / Meet the Craftsman

Create a personal section introducing my father.

Title:

"Meet the Craftsman"

Write the section in a warm, authentic tone.

Explain that he has years of hands-on experience working with tiles and takes pride in delivering clean, precise, and durable work.

Emphasize:

Experience

Attention to detail

Proper alignment and finishing

Quality workmanship

Reliability

Pride in every project

Include a professional portrait/photo area for my father.

Make this section feel personal rather than corporate.

Use a quote-style statement such as:

"Every project is a reflection of my work, so I believe in doing it right."

Do not invent specific years of experience, certifications, awards, companies, or qualifications. Use placeholders where information is not provided.

3. Services

Create a visually attractive services section.

Title:

"What I Do"

Create service cards for:

Floor Tile Installation

Professional installation of floor tiles with careful leveling, spacing, and finishing.

Wall Tile Installation

Clean and precise wall tile installation for kitchens, bathrooms, and other spaces.

Bathroom Tiling

Complete bathroom tiling with attention to layout, edges, corners, and finishing.

Kitchen & Backsplash

Tile installation for kitchen walls, backsplashes, and decorative areas.

Marble & Stone Work

Installation and finishing of marble, stone, and other premium surfaces where applicable.

Tile Repair & Replacement

Replacement and repair of damaged or worn tiles.

Keep the service descriptions concise and professional.

4. Project Gallery

This should be one of the most important sections of the website.

Title:

"Selected Work"

Create a beautiful masonry/grid gallery of completed tile projects.

Each project should support:

Large project image

Project title

Category

Short description

Optional location

Optional date

Create category filters:

All

Bathrooms

Kitchens

Floors

Walls

Marble & Stone

Other

When a visitor clicks an image, open a polished lightbox/gallery showing the larger image and project information.

Use placeholder project images initially, but make it extremely easy for me to replace them with my father's actual work photos.

Do not generate fake claims about projects.

Example placeholder project names:

Modern Bathroom

Marble Floor

Kitchen Backsplash

Residential Floor

Feature Wall

Custom Tile Work

Clearly structure the data so I can replace these later.

5. Why Choose His Work

Create a section explaining the qualities of his work.

Title:

"Craftsmanship You Can See"

Create 4 feature cards:

Attention to Detail

Careful alignment, spacing, edges, and finishing.

Quality Workmanship

A focus on clean and durable installation.

Reliable Service

Professional communication and commitment to completing work properly.

Pride in Every Project

Every completed project is treated as a reflection of his craftsmanship.

Use subtle icons and animations.

6. Before & After

Create an optional "Before & After" section.

Allow paired images showing the transformation of a space.

The layout should clearly show:

BEFORE → AFTER

This section should be easy to populate with actual project photos later.

7. Testimonials

Create a testimonials section with placeholder testimonials.

Important: Do NOT invent fake customer testimonials and present them as real.

Instead, use clearly marked placeholder content such as:

"Customer testimonial will appear here."

Make it easy for me to replace these placeholders with real testimonials later.

8. Contact Section

Create a strong contact section
